# 全屏地图改版 · v1.0.1

用户要求把线路图作为主角，参考高德/苹果地图的悬浮控件布局。本轮保留官方 SVG 站点、线路几何与官方首末班逻辑。

## 改动

- 地图铺满浏览器窗口，不再使用上方标题区、固定侧栏与下方整行面板分割画布。
- 左上浮窗：搜索车站、筛选线路、统计与时刻入口；右侧：缩放、市区、全图、站名、浅深色切换。
- 底部悬浮时间轴默认精简，日期、夜间范围与预设时刻收进“设置”。
- 点击站点或搜索后才打开可关闭的时刻卡；手机详情开启时，把选中站点移到详情卡与时间轴之间。
- 图例、官方数据边界、GitHub 与版本集中到“ⓘ”说明卡。Esc 关闭面板，触摸平移与鼠标拖动保持可用。
- 浅色详情用正常正文颜色，线路色改为侧边标记，避免亮色线路文字在浅底上难辨。

## 验证

36 项测试、生产构建、版本及 README 校验通过。浏览器实测鼠标拖图、无效搜索、站点卡开关、设置展开、线路筛选、跨午夜切换。

视口 1440×1000、1280×800、768×1024、390×844、320×640 与 844×390：地图占满窗口，文档无横向或纵向溢出；手机详情选站落在两个面板之间。手机仅浏览器模拟，未真机验证。

复用先前已核验的官方地图与数据，没有新增或推算时刻。参考了 [Apple Maps 网页](https://maps.apple.com/) 的地图主画布、搜索与独立地图工具布局；苹果地图底图在当前网络未渲染，参考仅限已实际显示的界面结构。

新截图：assets/screenshot.png、screenshot-dark.png、screenshot-mobile.png。全图视图用于观察全网变化；阅读具体站名仍建议“站名”放大。
